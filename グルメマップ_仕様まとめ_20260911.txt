【仕様書・機能概要】地区特化 グルメマップ（index.html）
================================================================================

1. アプリケーション概要
--------------------------------------------------------------------------------
・Leaflet.js（OpenStreetMap）を活用したWebベースの地区特化型グルメマップアプリケーション。
・地図上へのピン配置による店舗・エリア情報の登録、編集、閲覧、検索機能を提供。
・アカウント管理、複数マップ管理、データ共有（コード発行）、JSONバックアップ/復元、テーマ切替機能を実装。


2. 画面構成およびUIレイアウト
--------------------------------------------------------------------------------
【画面構成】
・地図表示エリア (#map)
  - 全画面（100vw × 100vh）表示の Leaflet マップ。
・上部バー (.top-bar)
  - 店舗数インジケーター（クリックで「登録店舗一覧モーダル」を表示）
  - エリア移動用セレクトボックス
・画面左上 (.top-left)
  - 「置いたピンを店舗登録」ボタン
  - 「エリア登録」ボタン
・画面右上 (.top-right)
  - 「操作 (☰)」ドロップダウンメニュー
    （アカウント管理、マップ管理、共有・バックアップ、テーマ設定）
・画面下部エリア (.bottom-container)
  - 画面下部左側 (#left-panel): 店舗絞り込み検索フォームおよび検索結果リスト
  - 画面下部右側 (#right-panel): 選択店舗の詳細表示（画像スライダー、各属性情報、操作ボタン）
・モーダルダイアログ (#modal-overlay)
  - 店舗・エリア登録/編集フォーム、店舗一覧、アカウント関連、マップ管理などを表示。

【レスポンシブ対応】
・画面幅 768px 以下のモバイルデバイス向けにフォントサイズ、パディング、パネルの縦並び配置を自動調整。


3. データ構造およびシステム制限仕様
--------------------------------------------------------------------------------
【ストレージ】
・localStorage を使用してブラウザローカルに保存。
  - ログイン時: gourmet_users / gourmet_current_user
  - ゲスト時  : gourmet_guest_maps / gourmet_guest_map_id

【権限・ゲスト制限】
・ゲスト状態では店舗/エリアの追加・編集・削除、新規マップ作成、復元などの操作時にログインを要求。

【マップデータ】
・1アカウント / 1ゲスト環境につき 最大20件 まで作成可能。

【店舗データ (stores)】
・1マップにつき 最大50件 まで登録可能（50件到達時は最古データの削除・上書き確認）。
・保持属性:
  - ID (id), 緯度 (lat), 経度 (lng)
  - 仮保存フラグ (isTemp)
  - お気に入りフラグ (fav)
  - 画像データ配列 (images): Base64形式、最大5枚、.png/.jpg 対応
  - 店舗名 (name)
  - 形式 (form): レストラン, ダイニング, ビュッフェ, カフェ, カフェダイニング, 料亭, 小料理屋, 定食屋, 居酒屋, バー, 屋台, 野外 (12種)
  - ジャンル (genre): 和食, 洋食, 中華, 韓国, アジアン, エスニック, 寿司, 焼肉, 麺類, パン系, スイーツ系, マルチジャンル, その他 (13種)
  - 予算 (budget): 1000円以内, 1000-3000円以内, 3000-5000円以内, 5000-7000円以内, 7000-10000円以内, 10000円以上 (6種)
  - 特徴 (charter/course/drink/eat): 貸切, コース, 飲み放題, 食べ放題 (各Boolean)
  - ピン形状 (shape): ● 丸形 (circle), ★ 星型 (star), ▼ 逆三角 (triangle)
  - ピンカラー (color): 8色固定カラーパレットから選択
  - 連絡先 (contact), 予約有無 (reserve)
  - リンク (site / tabelog / hotpepper / othersite)
  - 備考 (memo): 最大1500文字

【エリアデータ (areas)】
・1マップにつき 最大20件 まで登録可能。
・保持属性: ID (id), エリア名 (name), 緯度 (lat), 経度 (lng)


4. 詳細機能仕様
--------------------------------------------------------------------------------
(1) ピン配置・地図操作
  - 地図上のタップ/クリックにより指定位置へ仮ピン (tempMarker) を配置。
  - 配置されたピン座標を元に店舗登録またはエリア登録を実行。

(2) 店舗登録・編集・削除
  - 店舗名、各種分類、画像、ピンのデザイン（形状・色）を設定可能。
  - 「仮保存」機能によりピンをグレー表示で登録可能。
  - 登録済みの店舗情報は詳細パネルから再編集・削除が可能。

(3) 店舗詳細表示・スライダー
  - 複数画像が存在する場合、左右矢印ボタン付き画像スライダーおよび枚数インジケーターを表示。
  - 近隣店舗（一定距離内）が存在する場合、「<」「>」ボタンでスムーズな店舗切り替えが可能。
  - 有効なURLが入力されている外部リンクのみをアコーディオン形式で表示。

(4) エリア移動・店舗一覧表示
  - 上部バーのドロップダウンから登録済みエリア座標へ地図視点を即時移動。
  - 店舗数インジケーター（店舗: X/50 📋）から全登録店舗のアコーディオン付きモーダルを表示。
  - モーダル内の店舗項目を展開すると、対象店舗の座標へ地図が自動パン移動。

(5) リアルタイム絞り込み検索
  - 店舗名（部分一致）、形式、ジャンル、予算、各種特徴チェックボックスによる検索。
  - 条件入力時に画面下部左側パネルへ該当件数と対象店舗リストをリアルタイム表示。

(6) ユーザー認証・アカウント管理
  - メールアドレスおよびパスワード（6文字以上）による新規登録・ログイン。
  - ゲストデータが存在する状態でログインした場合、データを統合（引き継ぎ）する機能。
  - ニックネーム変更機能。
  - パスワード再設定画面の模倣（アドレス確認後に新パスワードへ更新）。

(7) マップ切替・新規作成
  - 複数のグルメマップを作成・切り替え・名称変更する機能。

(8) データ共有・バックアップ/復元
  - 共有コード発行: マップ全体または単一店舗のデータを Base64 文字列として発行・読み込み。
  - バックアップ: 全マップデータを JSON ファイル (gourmet_map_backup_[timestamp].json) としてダウンロード。
  - 復元: JSON ファイルを選択・読み込むことでデータを復元。

(9) デザインテーマ切替
  - html の data-theme 属性の切り替えにより以下の5テーマを適用:
    ・casual (カジュアル / 標準)
    ・simple (シンプル)
    ・pop (ポップ)
    ・light (ライト)
    ・dark (ダーク)
